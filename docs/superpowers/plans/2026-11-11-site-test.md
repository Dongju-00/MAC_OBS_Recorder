# Automatic Site Setup Plan

> **For agentic workers:** Use superpowers:executing-plans for implementation.

**Goal:** `--test` discovers the current site's navigation, verifies a 10-second OBS recording and a real media transition, then saves a local profile automatically used by `--run`.

**Architecture:** Extend browser diagnostics with conservative semantic next-control detection and unique reusable selectors. Store profiles by exact HTTP(S) origin in a gitignored JSON file beside the scripts. Explicit nonempty selectors override profiles. Revalidate targets before use. A verified YouTube Shift+N fallback handles absent buttons; arbitrary sites never receive guessed shortcuts.

**Constraints:** Python standard library only. Preserve existing modes and explicit JSON config support. Never overwrite source or config templates. Save profiles only after complete successful test, retaining other sites. Pause and stop on failures and interrupts; preserve recordings started outside this invocation. No claims of perceptual audio/video verification. Test changes the current page and leaves the next video paused. Tests use OBS only, since EaseUS cannot verify files. Fullscreen must be exited before clicking a control outside the video.

**Review Focus:** Ambiguous targets, duplicate selectors across frames, recording/save failure, media changing before navigation, profile isolation/corruption, focused-tab loss, actual media-time progress in short test, user selector overrides, stale profile handling, playback accidentally continuing after test.

Follow-up live debugging: YouTube's unrelated page-level `다음` button was excluded from automatic discovery. Native event probing then showed AppleScript text `keystroke "n" using {shift down}` delivered Alt+Shift+N under the current Korean input source. Physical ANSI N (key code 45) delivered Shift without Alt. Shortcut generation now uses physical ANSI codes for letters and digits. A live automated Shift+N changed both the YouTube URL and media identity, loaded the new player, and paused it. All 60 Python tests, browser tests, and diff checks passed afterward. Full OBS recording was not rerun by the agent.
